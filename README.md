# Big-Data-Analytics-Rakamin-Academy-x-Kimia-Farma
This repository contains my Big Data Analytics project completed during the Rakamin Academy x Kimia Farma Virtual Internship Program. The project focuses on analyzing pharmaceutical sales data using big data technologies to derive actionable business insights for Kimia Farma's operational optimization.
---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
📊 Project Overview
This repository contains my Big Data Analytics project completed during the Rakamin Academy x Kimia Farma Virtual Internship Program. The primary objective of this project is to evaluate Kimia Farma's business performance from 2020 to 2023 through comprehensive data analysis and visualization.

🎯 Project Objectives
1. Assess overall business performance trends across the 2020-2023 period
2. Identify key drivers of sales growth and decline
3. Evaluate operational efficiency across different branches
4. Provide data-driven insights to support strategic decision-making

📋 Project Challenges
Challenge 1: Data Import to BigQuery
Successfully import four datasets provided by Kimia Farma into Google BigQuery:
 * kf_final_transaction - Transaction records
 * kf_inventory - Stock and inventory data
 * kf_kantor_cabang - Branch office information
 * kf_product - Product catalog details

Challenge 2: Analytical Table Creation
Create an integrated analytical table in BigQuery that combines and transforms data from all four imported datasets, enabling comprehensive business performance analysis.

Challenge 3: Performance Dashboard Development
Design and build an interactive performance dashboard using Google Looker Studio that visualizes key business metrics derived from the analytical table, facilitating easy monitoring and insights generation.


🛠️ Technologies Used
1. Data Warehouse: Google BigQuery
2. Data Visualization: Google Looker Studio
3. Data Processing: SQL (BigQuery Standard SQL)
4. Version Control: Git & GitHub
